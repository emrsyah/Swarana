# Design files

Drop exported designs here. I read this folder before building each screen.

```
design/
  v5/
    screens/   one PNG per screen/state, e.g. obrolan_2_speakers.png
    tokens/    design system page export + colors/typography (screenshot or JSON)
    assets/    icons, illustrations, board symbols (SVG preferred)
  v3/          optional, only if v3 Figma differs from the repo code
  links.md     Figma frame links, if you have them
```

Name screen files after what they show (`transkrip_live.png`, `obrolan_noise_alert.png`).
Export at 2x so text is readable.
